# HeatmapGeneratorWebApp

## Usage
[Click here](https://danelimjoco.shinyapps.io/MyHeatmapsWebApp/) to try the application. 

When prompted to "Choose count data file", upload the countData.xlsx file provided in this repo. 

When prompted to "Choose metadata file", upload the metadata.xlsx file provided in this repo. 

Use the sliders to select how many low-count genes to filter out and how many genes you'd like for your heatmap. Give the app some time to calculate once you confirm how many genes you want to analyze. A heatmap should appear and will reactively update as you adjust sliders again.
