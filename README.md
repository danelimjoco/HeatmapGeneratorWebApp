# HeatmapGeneratorWebApp

## Usage
[Click here](https://danelimjoco.shinyapps.io/MyHeatmapsWebApp/) to try the app!

### Count data file
When prompted to "Choose count data file", upload the countData.xlsx file provided in this repo. 

### Metadata file
When prompted to "Choose metadata file", upload the metadata.xlsx file provided in this repo. 

### Filter out low counts
Use the slider to select how many low-count genes to filter out.

### Number of genes to analyze
Use the slider to select how many genes will appear on your heatmap. Genes are ranked by differential expression, so just choose the top X genes to display.

Give the app some time to calculate once you confirm how many genes you want to analyze. 

### Heatmap
A heatmap should appear and will reactively update as you adjust sliders again.
